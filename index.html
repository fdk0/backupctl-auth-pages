Private backup utility

Backupctl

Encrypted backups to an owner-controlled Google Drive.

Backupctl is a personal, owner-operated backup utility. It prepares backups from selected sources on the owner’s Ubuntu system, encrypts backup contents locally with Duplicity, and uses rclone to store the resulting backup volumes in the owner’s Google Drive.

This application is for the owner’s private use. It does not offer public registration or onboard third-party users.

Limited Google Drive access

The Google Drive integration requests the drive.file permission to create and manage its own backup files and folders. It is intended to use a dedicated backup namespace, rather than browse unrelated files already in the account.

Owner-controlled recovery

The owner controls which sources are backed up, the backup schedule and retention settings, and when backup data is restored or deleted.

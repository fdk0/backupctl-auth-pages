Backupctl

Privacy notice

Last updated: 14 November 2026

This notice describes Backupctl, a private backup application operated by its owner. It is not a public backup service and does not offer third-party account registration.

Data and purpose

Backupctl processes the files, directories and recovery material selected by the owner to create backups and support restoration. Backup contents are encrypted locally by Duplicity before rclone uploads the resulting volumes to the owner’s Google Drive. Operational metadata, such as backup timestamps and completion records, can be stored alongside those volumes.

Google Drive permissions

The integration requests the narrow drive.file scope to create, read, update and delete the backup files and folders it creates. The application is intended to work within its own backup namespace, without browsing unrelated existing Drive files.

OAuth credentials and authorization tokens are stored on the owner’s system to allow authorized backup operations. They are not published on this website or intended to be shared through repository issues.

Storage, access and sharing

Backup data is stored in the owner-controlled Google Drive account and local backup working storage. The owner controls access and use. Backupctl does not sell data, run advertising or share backup data for marketing. Google processes data stored on its services under its applicable terms and Google Privacy Policy.

Retention and deletion

The owner controls backup retention settings and may delete local or remote backup data. Removing OAuth authorization prevents future authorized access by the application; it does not itself delete backup files already stored in Google Drive. Google Drive’s own deletion and trash behavior also applies.

This information website

These static pages contain no advertising, analytics scripts, forms or account signup. GitHub Pages hosts the site and may process visitor request information under the GitHub Privacy Statement. Public repository issues are visible to others.

Contact and changes

Questions about this application or notice can be raised with the owner through the repository’s issue tracker. Do not include tokens, passwords, client secrets, private file contents or backup archives. This notice may be updated when the application’s handling of data changes.
